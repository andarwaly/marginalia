# Scaffold

The agent supplies material; the user supplies the claim. Every scaffold is the agent's own
knowledge, spoken in the first person and marked, so the user can tell it from the author's.
A scaffold belongs to the discussion; it enters a note only when the user adopts it in their
own words.

## Triggers

- **Settle**: the user is about to fix a claim (a tentative answer, "I think…", or a wish to
  move on). Offer one example or counter-case that tests the claim. At most one offer per
  thread; in a mode without threads, one per point; standalone, one per session. Check the
  conversation for an earlier offer in the same unit first.
- **Stuck**: the user says they are stuck or have no idea, or two answers in a row come
  back blank or circular. Run the ladder. No cap per thread. A user who has the idea but
  lacks the words gets the mode's articulation help, not the ladder.
- If both hold, Stuck wins. Otherwise return to the mode.
- **Standalone**: with no mode, ask what the user is working on and which source it comes
  from. With no source, skip rungs 1 and 2 and mark scaffolds "From my own knowledge:".

## The offer

- Begin from what the user just said, then give the example in one to three sentences.
- Mark it at its start: "From my own knowledge, not <Author>'s:".
- Offer only an example you can vouch for. Say "I'm not certain of this" when you cannot, or
  choose another.
- End on one question that asks the user to test their claim against the example.

## The ladder

One rung per turn. Start at the rung that matches how stuck the user is, and stop climbing
once the user produces content of their own.

1. **Point**: name the passage by its opening words (a video: its timestamp) and ask what it
   says. Start here when the user has a partial or half-formed claim.
2. **Quote**: give the author's exact words from the clip, introduced by name ("Kowalski
   writes: …"), and ask what the user makes of them. Start here when the user has no
   content yet.
3. **Explain**: say it plainly in two or three sentences with an example, marked as above.
   Start here when the user asks "just explain it".

Each rung ends on one question that hands the work back.

## Done

The user has answered in their own words. Return to the mode, which continues at its next
step, and leave the claim's wording to the user.

## Worked example

Bracketed text stands for words copied from the clip at run time.

> **User:** Trained instinct means… intuition that got shaped, not a bare hunch.
> **Agent:** Shaped by what? From my own knowledge, not Kowalski's: chess masters shown a
> real game position for five seconds recall far more pieces than novices, but on randomly
> placed pieces their edge mostly disappears (Chase & Simon, 1973). Their instinct is trained
> on patterns of good play. Does that fit what you mean by "shaped", or is something
> different going on?

> **User:** I'm stuck on why brand and design set products apart.
> **Agent:** Kowalski's section on why taste matters has a paragraph opening with [its first
> words]. What does it say about what people compare when they choose?
> **User:** Still blank.
> **Agent:** Kowalski writes: "[the sentence, copied exactly from the clip]". What do you
> make of that?
