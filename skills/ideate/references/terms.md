# Terms

Read when a rule in SKILL.md is unclear.

- **Thought note**: an atomic idea of the user's own, optionally backed by source notes.
  The title and filename are a full claim sentence with the `✱` prefix.
- **Verb**: what the user wants done with the idea.
  - sharpen: make the statement clearer and sharper.
  - refine: improve a statement that is mostly there.
  - validate: test it against evidence or objections.
  - extend: ask where it leads and what it connects to.
- **Backing**: the notes or sources the user names or pastes. There is no vault search.
- **Basis tag**: [note: quote], [source: URL], [reasoning] or [unverified].
- **Position**: the agent's view of the user's claim: agree, disagree or partly.
- **Statement gate**: the user's open confirmation ("what's missing or wrong?") fixes a
  statement.
- **Done gate**: the "so what" question, then the sign-off pass, then the note.
- **Purity check**: every sentence of a thought note says something no single cited note
  said alone. Applies only when the note cites others.
- **Sign-off criteria** (five): the title is a claim; the note stands alone; it is about one
  thing; every link has a reason; it answers or spawns a "so what".
- **Scoped claim**: a claim that says where it holds, and that the user can defend.
