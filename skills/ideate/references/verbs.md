# Verbs and techniques

Read at step 2. The verb comes from the user's words; the technique follows it. Switch
within a session if the user's aim changes.

| Words | Verb | Technique | First move |
| --- | --- | --- | --- |
| "make this clearer", "tighten" | sharpen | `feynman-technique` | Ask for it in plain words to someone with no background. |
| "is this right?", "does my note say it" | refine | `verification-technique` (against pasted notes) | Point to the note passage. |
| "I'm not sure this holds" | refine | `elenchus-technique` | Needs a located weakness; if none, say so. |
| "test this", "poke holes" | validate | `compass-technique` East | State the strongest opposing case, tagged, then ask. |
| "where does this go?", "what else?" | extend | `compass-technique` South, West | Ask where it leads; the user supplies the content. |
| "I have a feeling that..." | (hunch) | `maieutic-technique` | Ask toward the hunch; the position stays the user's. |
| "I'm stuck", "I can't put it into words", a tentative claim | (any) | `scaffold-technique` | One tagged example, or the ladder. |

If the words fit two verbs, ask one question: "Do you want to test this, or sharpen the
wording?"

Validate with no backing: ask once, "do you have a note or source that backs this?" If not,
challenge the user's reasoning alone, tagged [reasoning]. Below the note: "Not validated
against a source."
