# Statement gate

Read before fixing any statement: a point, or the main idea. A statement is fixed only
when the user, shown the draft, answers the open question and adds nothing that changes it.

The draft is built from what the user said, in their wording where possible. The agent adds
no claim the user did not make.

Ask: "Here's what I have, from what you said: <statement>. What's missing or wrong?"

| The user says | Fixed? |
| --- | --- |
| "Nothing, that's it." | Yes |
| "Add that it only works early on." | No. Revise, ask again. |
| "Yes." / "Sure." / "Sounds right." | No. Ask again, naming one part and asking whether it is right. |
| (changes the subject) | No. Return to the draft once; if the user moves on, leave the point unconfirmed. |

An unconfirmed point is not written. The step 6.1 nudge offers it once more.
