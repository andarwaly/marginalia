# Admission

Read at step 3. Run the checks in order. Stop at the first that fails.

1. **Not an entity.** People, places and organizations are not admitted; they stay as
   mentions. A named tool, event, framework or creative work is fine.
2. **Stable identity.** A reusable label a future reader can look up the same way. A coined
   label counts only if it means something outside the one source that coined it.
3. **Source independence.** The definition stands without one source's wording or private
   context. A source-specific term with no independent support is unresolved.
4. **Bounded.** One coherent concept, not a whole topic or a whole source.
5. **Enough evidence.** One authoritative source can admit a settled standard. Otherwise
   two independent support paths whose support is not a repeat of each other. Notes with the
   same URL or the same author are one path. A contested definition needs independent
   support for each competing version, or the user's explicit choice.
6. **Natural unit.** A named framework with dependent steps is one entry; its steps are
   sections inside it, never separate entries.

## Examples

- "taste", notes from Kowalski and Atluru, different URLs and authors -> two paths. Admitted.
- "taste", three notes from Kowalski's one article -> one path. Unresolved at check 5:
  "Only Kowalski supports this; I need one independent source." "Write it anyway" gives the
  caveat line.
- "Kowalski" -> check 1 fails: a person.
- "the four-question review", with each question as its own request -> check 6: one entry
  for the method, the questions inside it.
- "design" -> check 4 fails: a whole topic. Ask which concept inside it.

## Wording the definition

Take the notes' characterizations. Where they agree, use their wording. Where they differ in
degree, merge into one sentence that holds for both. Where they conflict, stop and ask:
"Kowalski says X; Atluru says Y. Which holds, or shall I state both?"
