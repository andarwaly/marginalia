# Guided reading

## What it is

An adaptive collaboration mode for a source the user has not started or has only
partly read. It helps the user make a first, source-owned understanding without
turning the conversation into a fixed script. The agent chooses the next useful
move from the user's signal and the reading context.

Start: if a mode called this, its inquiry, passage and surrounding material are
the entry point; do not reopen with a fixed restatement opener, because the mode
already supplies the question that made reading relevant. Run on its own, ask
which source or passage, and what the user wants to understand from it.

**Reach for this when** a source is present, the user's understanding of it is
not yet established, and the user works through it together: they said they have
not read it fully, or their answer about a passage came back blank.

**Do not use this when** the user wants to read independently or finish reading
first (say they can come back to it, with no choice
card or prediction exercise), when a clear restatement is ready for
`verification-technique`, or when no source is available (`maieutic-technique`
fits that case).

## Route into collaboration

Called by a mode or named by the user, collaboration is already chosen: begin
with the passage, and do not offer a choice between reading alone and working
together. Only when the user's wish to read alone is unclear, ask which they
prefer, in plain language, without labeling the options as a diagnostic state or
presuming that collaboration is better.

## Adaptive moves

Choose one move per turn, based on what would make the next part of the source more
understandable:

- **Explanation** — invite the user to put the current passage or idea in their own
  words when they have enough material to attempt it.
- **Clarification** — narrow to one ambiguous word, relationship, or transition when
  the user's account is close but unclear.
- **Comparison** — ask how the current passage differs from or extends something
  already read when that contrast is the useful hinge.
- **Retrieval** — ask the user to recall a relevant earlier passage or point before
  supplying it again.
- **Prediction** — invite a best guess about what the source may do next when the
  preceding material supports a meaningful inference.

Prediction is one available move, not a ritual. Do not require a prediction before
every passage, and do not reveal a passage merely to keep a predetermined cadence.
Explanation, clarification, comparison, or retrieval may be the better next move.

## Calibrate support

Keep the question open enough for the user to supply the substance. Add a small hint,
such as the relevant relationship or a short pointer to where to look, only when the
user is stuck or misses the source's direction. Withdraw that support after the user
is answering cleanly; restore or increase it when the user stalls again. A hint never
answers the question itself; when the user is still stuck after a hint, call
`scaffold-technique`, whose ladder can end in a plain explanation. Summarize the whole
passage only when the user asks, and name any repair of the user's interpretation aloud.

Reveal only the amount of source material needed for the current move, then pause for
the user's response. A passage may be shown before an explanation, clarification,
comparison, retrieval, or prediction question when the question concerns material
already supplied; a next passage need not always be gated by prediction.

Ask wide before narrow. Do not announce the source's structure inside a question
("what do its three arguments claim?" hands over that there are three); ask what the
passage is claiming, and narrow to one part only if that stalls.

## Guardrails

- Ask exactly one substantive question per turn.
- Preserve the source's posture, attribution, uncertainty, and scope.
- Build each turn on the substance of the user's last answer, then ask the question on
  its own line.
- Build the accumulated understanding from the user's words; do not hand over a
  polished conclusion prematurely.
- At Done, hand back the whole accumulated result once, not each move. If only
  part of the source was worked through, say which part, and hand back only that.

## Done

The user has a first understanding of the passage in their own words. Return the user's statement, verbatim, to the mode that called this technique; the mode continues at its next step. Run on its own, say the statement back once and stop, with no notes.
