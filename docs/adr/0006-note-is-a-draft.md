# The note is a draft; the discussion is the product

Status: accepted. Supersedes 0004. Amends 0005.

The owner (2026-11-05) rewrote a converted source note by hand and named what they use the skills for: sharpening their own thinking and understanding of the author, not producing a finished note. The agent's output is a starting point they refine into prose, and its layout matters less than what it records. The same holds for `ideate` and `define`; only the content differs. `CONTEXT.md` names it a Draft, and each mode states it in its intro.

For `ingest` the draft records what the owner listed: each point, their own words, what the author says, the author's examples, the people the author quotes, the lines they pick, Key Concepts and Mentioned. Changes from 0005:

- Why I'm here and the main idea are not written. The Intention still steers the interview. Wrap-up step 3 (the main idea) is gone.
- Open Questions has no section. A question the source does not answer stays as the user's own bullet, word for word.
- Frontmatter is `author`, `published`, `url`. A vault template may add its own fields and keeps its own layout.
- New: an `Example:` entry for each example the user has seen, and a `Quoted:` entry for each person the author quotes in a seen passage, both verbatim from the clip. They are the only source text the agent places on its own; a Quote is still only a line the user names, and one that is both is written once, as the Quote.
- Key Concepts and Mentioned stay at the foot; the owner's note replaces them with inline links, which the owner adds when refining.

0004 is superseded: bracketed referents are dropped. A bracket names what "it" or "b" stands for but does not restore the question the fragment answered, and a thought's context comes from its place under a source point beside the claim line. Implications are the user's words, joined by concatenation, with nothing added.

Considered: keep the brackets as draft scaffolding (rejected: the owner reads them as adding little); write the note in prose as the owner does (rejected: the agent would write the owner's opinions; bullets are easier to merge, cut and reorder). Risk: a draft left unrewritten keeps fragments that read poorly without the chat; the End review shows the whole draft to catch this. A note that holds `Example:` and `Quoted:` text grows longer; the owner trims it at the End review.
